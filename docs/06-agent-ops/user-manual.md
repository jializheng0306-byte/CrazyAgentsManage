# CrazyAgentsManage 用户使用手册

## 概述
CrazyAgentsManage是一个多Agent协作管理平台，用于展示Hermes-Agent和FlowMind项目的整体运行状态。本手册将帮助您快速上手使用该系统。

## 快速开始

### 1. 系统访问
- **飞书群**: CrazyAgentsManage
- **多维表格**: [任务管理表](https://bcn7uazoofu0.feishu.cn/base/HlUlbPTEoa2FlssAUScciqo4nTe)
- **GitHub仓库**: jializheng0306-byte/CrazyAgentsManage

### 2. 基本操作

#### 发送消息
在飞书群中直接输入消息，HermesAgent会自动响应。

**示例**:
```
你好
帮我设计一个登录页面
查看当前承诺状态
```

#### 使用@mention
需要特定Agent响应时，使用@mention。

**示例**:
```
@HermesAgent 帮我创建一个承诺
@codex cli 查看代码提交状态
```

## 功能详解

### 1. 承诺管理

#### 创建承诺
告诉HermesAgent您的需求，系统会自动创建承诺记录。

**示例**:
```
用户: 帮我设计一个登录页面
HermesAgent: 我来帮你创建一个承诺记录。
- 交付物: 登录页面设计稿
- 截止时间: 本周五
- 验收标准: 包含用户名/密码输入框、登录按钮、忘记密码链接
```

#### 查看承诺状态
```
查看当前承诺状态
列出所有待处理承诺
查看即将到期的承诺
```

#### 完成承诺
当任务完成后，通知HermesAgent进行验收。
```
登录页面已完成，请验收
```

### 2. 知识管理

#### 晨间情报 (08:30)
每日08:30自动采集技术情报，包括：
- 技术博客更新
- 学术论文
- 行业新闻

#### 午间论文 (12:00)
每日12:00自动解读最新论文，包括：
- 论文摘要
- 关键发现
- 应用场景

#### 晚间趋势 (20:00)
每日20:00自动分析技术趋势，包括：
- 技术趋势
- 行业动态
- 机会识别

#### 每日反思 (23:00)
每日23:00自动总结当日工作，包括：
- 完成情况
- 效率评估
- 改进计划

### 3. 协作功能

#### 与Codex CLI协作
HermesAgent负责运营，Codex CLI负责开发。

**协作流程**:
1. **Request**: HermesAgent提出需求
2. **Confirmed**: Codex CLI确认接收
3. **Final**: Codex CLI完成交付

**示例**:
```
HermesAgent: @codex cli 需求: 设计登录页面
Codex CLI: @HermesAgent 确认: 已收到需求，预计3天完成
Codex CLI: @HermesAgent 完成: 登录页面已提交，commit abc123
HermesAgent: @codex cli 验收: 通过
```

#### 查看协作记录
```
查看最近的协作记录
查看Codex CLI的提交
查看代码审查结果
```

### 4. 报告功能

#### 查看审查报告
```
查看今日承诺审查报告
查看本周承诺统计
查看承诺完成率
```

#### 查看趋势报告
```
查看今日技术趋势
查看本周趋势分析
查看行业动态
```

## 最佳实践

### 1. 承诺管理最佳实践
- **明确需求**: 清楚描述交付物、截止时间、验收标准
- **及时更新**: 任务进度变化时及时通知
- **按期验收**: 任务完成后及时验收
- **记录反馈**: 验收后记录反馈意见

### 2. 协作最佳实践
- **使用@mention**: 需要特定Agent响应时使用@mention
- **结构化消息**: 使用统一格式减少沟通轮次
- **及时同步**: 进度变化及时通知
- **记录协作**: 重要协作记录保存

### 3. 知识管理最佳实践
- **定期查看**: 每日查看情报、论文、趋势
- **整理笔记**: 将有价值内容整理成笔记
- **分享知识**: 将有价值知识分享给团队
- **应用知识**: 将学到的知识应用到工作中
